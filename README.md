# Bibliotheca

An interactive prototype of a reading workspace for books, notes, and the connections between ideas.

[Open the demo](https://marziehzzare.github.io/bibliotheca/) after GitHub Pages is enabled.

## What this release is

This is a static demo with sample books and prewritten insights. Sign-in, magic links, AI analysis, and profile saving are not connected to services. The demo does not request account credentials. Changes made in the interface are not a reliable personal library and may disappear when the page reloads. Do not enter sensitive or unpublished material.

The page loads Inter from Google Fonts and may request public book-cover images from Open Library. The source is a single HTML file with embedded styles and scripts.

## Run locally

Open index.html in a browser, or serve this directory with a static web server. No build step is required.

This release contains only the demo page and this README. The wider design folder and planning documents are not part of the public repository.
